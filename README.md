## 🏗️ Portfolio Tech

This portfolio is built with pure **HTML + CSS + Vanilla JS** — no frameworks, no build tools.

```
portfolio/
├── index.html          # Main page
├── css/
│   ├── tokens.css      # Design system variables
│   ├── layout.css      # Page layout & sections
│   ├── components.css  # Buttons, cards, forms
│   ├── animations.css  # GSAP animation classes
│   ├── typography.css  # Font styles & hierarchy
│   ├── responsive.css  # Mobile breakpoints
│   ├── modal.css       # Project case study modal
│   ├── theme.css       # Light/dark theme toggle
│   └── reset.css       # CSS reset
├── js/
│   ├── main.js         # App entry point
│   ├── three-hero.js   # Three.js 3D hero canvas
│   ├── animations.js   # GSAP ScrollTrigger animations
│   ├── projects-data.js# Project case study content
│   ├── modal.js        # Case study modal logic
│   ├── contact.js      # Formspree form handler
│   ├── nav.js          # Navigation & mobile menu
│   ├── cursor.js       # Custom cursor
│   ├── loader.js       # Page loader animation
│   └── theme.js        # Theme toggle logic
└── Photos/             # Project screenshots & headshot
```

**Libraries used (CDN):**
- [Three.js](https://threejs.org/) — 3D hero canvas animation
- [GSAP + ScrollTrigger](https://gsap.com/) — Scroll-based animations
