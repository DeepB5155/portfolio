### 🔄 Automatic GitHub project sync

Every **public** repo you create appears in the **More from GitHub** section and in the **Project Universe** automatically — no code changes and no setup per repo. Two layers keep it current:

1. **Instant (live):** when someone opens the site, the browser asks the GitHub API which repos exist (`js/github-data.js`), so a new repo shows up — and a deleted/archived/private one disappears — right away. Results are cached for 10 minutes per visitor. If GitHub is unreachable or rate-limited, the site silently uses layer 2.
2. **Hourly (rich details):** a GitHub Action (`sync-projects.yml`) runs **every hour** (or on demand from the *Actions* tab) and rebuilds `data/github-projects.json` with code size, full language list, README summary and cover images. Netlify redeploys on that commit.

What gets pulled from the repo: name → title, description → summary (falls back to the README's first paragraph), languages and topics → tags, *Website* field → Live link, `screenshots/cover.png` (or the first README screenshot) → cover image.

Skipped automatically: forks, archived/private repos, the `portfolio` repo, the profile repo, and repos already featured in the hand-written case studies. To **hide** any other repo, add the topic `hide-from-portfolio` to it.

To run it locally: `node scripts/sync-github-projects.mjs`.

### 🎮 Core Defense — first-person shooter

A small "Just for fun" link under the hero buttons (and a floating **Fun game** pill) opens a full-screen Counter-Strike style FPS built with Three.js (`js/fps-game.js`, `css/game.css`). It is a bonus mini-game, deliberately low-key so the main focus stays on the work. You defend a server core in a cyber data center over 5 rounds:

- **Buy phase** before every round (like CS): spend money on an SMG, rifle or sniper, armor, a medkit or an auto-firing sentry turret. The intel panel shows which gates the next wave will attack from, so you plan your loadout.
- **Combat:** hostile bots (red visors) rush the core and shoot back; headshots do extra damage; weapons have recoil, reloads and a scope on the sniper.
- **Legit users** (green visors, labelled `USER`) walk to the core. Serving them earns money; shooting them costs money and score.
- **Training and help for first-time players:** the start screen explains Plan → Fight → Survive and offers a ~90 s guided training (buy, move, aim, shoot a red bot, spare a green user, reload) against slow, harmless bots. A `?` button opens the full rules, controls and planning tips at any time.
- **Planning aids in the buy phase:** a mini-map with the number of hostiles per gate, intel text, a context tip, "Recommended" badges, and an **Auto-buy** button. Sentries deploy toward the busiest gate. In combat a radar shows red enemies, green users and sentries.
- Controls: mouse look (pointer lock) + WASD, click to fire, `R` reload, `1-4` weapons, Space to jump, `Shift` to sprint, right-click to aim down sights (scope on the sniper), `F` to use a gate firewall or EMP terminal. On phones: on-screen joystick, drag-to-look, fire/reload/jump buttons and a context `USE` button. `Esc` pauses. Best score is stored in the browser. The other 3D scenes pause while the game is open.
- **Map hazards and objectives:** yellow **arc traps** in each lane flash amber then zap whatever stands on them (bots, users and you); a **firewall** at each gate (`F`) seals it for 7 s so bots wait outside (users too); two wall **EMP terminals** stun every bot once per round; a hidden **supply crate** (marked by a green beam) gives cash, ammo, armor, health or core repair.
- **Look and feel:** bloom glow and real-time shadows (desktop; bloom switches itself off if the device is slow), detailed bot models, bullet holes, muzzle light, ejected shell casings, floating damage numbers, headshot / kill markers and kill streaks, directional damage arcs and a low-health vignette.
- **Weapon animation:** per-weapon reload choreography (magazine drops and is re-seated, slide / bolt racked), sniper bolt cycle, slide recoil, weapon draw, sprint pose, aim-down-sights, mouse-look sway and a wall push-back pose.
- **Sound:** everything is synthesised with Web Audio (gunshots per weapon, footsteps, reload clicks, positional bot chirps, explosions, hazard sounds, heartbeat at low health) plus an adaptive music loop that gets more intense in later rounds. The speaker button turns sound on (it is off by default); the note button toggles music.

### 🌌 Project Universe

An interactive Three.js section that turns the same synced GitHub data into a **3D world** — switch between a **Galaxy** (planets) and a **City** (buildings):

| Visual | Meaning |
|---|---|
| Planet size / lit windows | How recently the repo was updated |
| Building height | Amount of code (bytes from the GitHub language stats) |
| Colour | Main language (C# is preferred when a repo contains it) |
| Ring around a planet | The repo has a live demo (Website field) |

New repos appear automatically. In the **Galaxy**, rockets fly between projects, an asteroid belt drifts around the sun, a space station and satellites orbit, comets cross the sky and a coloured nebula glows in the background. In the **City**, projects are buildings with name signs on a street grid with lane markings, lawns, parks with ponds and fountains, trees and street lamps. The city has moving cars, a tram, pedestrians, patrolling drones and a helicopter with a searchlight, two rivers crossed by bridges, and an optional **Rain** toggle. Repos created in the last 30 days are shown **under construction** (scaffolding, a slewing crane and dimmer windows) until they age. Unused lots become parks, so the city has room to grow.

Click a project to fly to it and see an **info card** (language breakdown bar, code size, stars, last update, and buttons for the case study, GitHub and live demo). Case studies are hand-written for featured projects and auto-built for the rest. A keyboard-accessible project list sits under the canvas and doubles as the fallback when WebGL is unavailable.

- [Three.js](https://threejs.org/) — 3D hero canvas animation
- [GSAP + ScrollTrigger](https://gsap.com/) — Scroll-based animations
